    2 способ. 
        - Зайти в админку, перейти на вкладку Управление администраторами
        - Нажать сменить пароль рядом с нужной учетной записью
        - Повторить действия из первого способа
    3 способ

# Для смены пароля пользователя делаем следующие шаги:
    1 способ. Сброс через профиль пользователя(если авторизован):
        - Перейти в профиль, нажать кнопку "Сменить пароль"
        - Вводим старый и новый пароль, нажимаем кнопку "Сменить пароль"
    2 способ. Сброс через кнопку "Забыли пароль?" на странице авторизации:
        - Вводим почту, на которую зарегестрирован аккаунт
        - Получаем ссылку для сброса, переходим по ней
        - Вводим новый пароль и спокойно заходим в аккаунт
